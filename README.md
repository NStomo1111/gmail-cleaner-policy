# gmail-cleaner

gmail-cleaner は、作成者本人が自分の Gmail を整理するための個人用ツールです。一般には公開・配布していません。

gmail-cleaner is a personal tool used only by its author to organize the author's own Gmail account. It is not distributed to the public.

## プライバシーポリシー / Privacy Policy

本ツールは Gmail API を通じて作成者本人のメールにアクセスし、不要メールの分類・削除のみに使用します。取得したメールのデータは本人の端末内でのみ処理し、外部サーバーへの送信や第三者への提供・共有は一切行いません。広告目的での利用もしません。

This tool accesses only the author's own mailbox through the Gmail API, solely to classify and remove unwanted mail. All data is processed locally on the author's own device. No data is sent to external servers, sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
